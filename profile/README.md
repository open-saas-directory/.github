# Open SaaS Directory

### Discover open-source alternatives. Choose software you control.

[Open SaaS Directory](https://opensaas.directory/) helps developers,
founders, and teams discover open-source SaaS alternatives and
self-hosted software.

Find tools for your next project, explore alternatives to your current
subscriptions, and connect with the repositories behind the software.

**[Explore the directory →](https://opensaas.directory/)**

---

## Find your next tool

Explore software for analytics, productivity, automation, collaboration,
developer workflows, and more.

- **[Browse categories](https://opensaas.directory/categories)** —
  discover tools organized by what you need to do.
- **[Explore SaaS alternatives](https://opensaas.directory/alternatives)** —
  find alternatives to familiar commercial products.
- **[Read the blog](https://opensaas.directory/blog)** —
  explore articles about open-source software and self-hosting.

Our goal is simple: make useful software easier to discover and give
people more choice over the tools they use and the data they share.
